# BLACKHOLE Laboratory Charter

BLACKHOLE asks whether a genuinely scratch-initialized compact language model can improve useful conversational behavior per deployed megabyte without hiding resource costs or borrowing pretrained capability. Experiments begin with empty weights. STATIC-0T may become the first adapter only after its owner-supplied source, license, tests, checkpoint semantics and approximately 1.9M-parameter architecture are inspected; it is not the permanent identity of the lab.

Learning goals are reproducible construction, measured byte-level cross-entropy improvement, held-out conversational behavior, deterministic checkpoint reload, inference memory/latency and honest ternary-versus-FP32 comparisons. Loss reduction alone is not conversational competence.

Boundaries: English text/chat first; no multimodal training, avatars, agents, STATICOS, STATIC_CORE or STATIC_GPT coupling. Dataset import and real training require separate owner authorization after license, quality, privacy and contamination review. Paid Jobs, GPUs, hardware changes and long-running compute also require task-specific authorization. Synthetic tensor tests are `TEST-ONLY` and are never reported as language training.
