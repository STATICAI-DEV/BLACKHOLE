# BLACKHOLE Laboratory Charter
**Created:** 2026-10-10 18:55 SAST | **State:** Reference

## Objective
Experiment with genuinely newly initialized STATIC language models and quantify **useful conversational quality per deployed megabyte**, training time, inference memory and latency. Avoid claiming novelty merely because an architecture has a different name.

## Initial experiment
- Named prototype: STATIC-0T, described in earlier starter materials as a gated causal-convolution ternary-weight experiment.
- Start with English text and conversation only. Other languages are archived candidates, not training inputs.
- Compare native ternary against a properly controlled full-precision baseline when resources permit.
- No pretrained weights, LoRA or fine-tuning for this particular from-scratch track unless the user changes the research objective.

## Success criteria
Reproducible model construction; valid training/validation loss improvement beyond initialization; held-out conversational evaluation; deterministic checkpoint reload; real resource measurements; fully traceable datasets and legal review. Conversational usefulness is a *separate* goal from mere loss reduction.

## Boundaries
BLACKHOLE is an independent experimental lab. Do not merge it with STATIC_CORE, StaticOS, STATIC_GPT or other workstreams merely because of similar names. Do not start paid compute, change model design, or declare work-state changes without explicit authorization. Codex owns Hugging Face deployment.
