# BLACKHOLE Lab Architecture (conceptual)
**State:** Planned, not a deployment claim | **Verified dataset bucket:** `hf://buckets/BluStatic/BLACKHOLE-DATASETS`

```text
Hugging Face: BLACKHOLE Space (NOT VERIFIED CREATED)
  dashboard: overview | datasets | training graphs | arena | chat
  training worker/job -> durable checkpoints and metrics
  dataset bucket -> raw/ curated/ manifests/ governance/provenance/
       |
       +--> explicit sanitized status exporter (NOT DEPLOYED)
                       |
                       v
GitHub STATICAI-DEV/BLACKHOLE (THIS REPOSITORY)
  docs/     study contracts, data register, evaluation and governance
  bridge/   immutable timestamped status snapshots and protocol
  reports/  signed or hashed run summaries when published
                       |
                       v
ChatGPT reads GitHub and optionally Hugging Face for freshness checks
```

**Data ownership:** training data and weights stay in Hugging Face storage; do not mirror raw files or credentials to GitHub.

**Reliability:** no assumption that a free CPU Space runs forever. Workers resume from persisted checkpoints and only claim progress verified by job state and metrics. Status exports must be atomic and fail closed when source metrics are unavailable.

**Cost:** any billed hardware, long-running scheduled job or paid API requires separate authorization.
